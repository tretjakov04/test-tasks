Для проверки первого задания используйте следующие команды из корня проекта (или из соответствующей папки задания):

Сверка заказов: php task1/sync.php 

Проверка исправлений: php bugs/OrderTotal.php 

Принятые решения (Задание 01)

Дубликаты заказов: Определяются по полному совпадению id. Если заказ уже был обработан, его копия игнорируется, чтобы не списывать остатки дважды.

Отмененные заказы: Заказы со статусом cancelled безопасно пропускаются. По ним не происходит резервации остатков на складе.

Невалидные данные: Если в ответе API у товара отсутствует цена, скрипт выводит предупреждение, но не падает, продолжая обработку остальных позиций.

Нормализация артикулов: Перед сверкой с базой 1С все артикулы приводятся к нижнему регистру, а лишние пробелы (в том числе неразрывные) удаляются. Это позволяет корректно сопоставлять товары вроде " ts-1002".

Подсчет остатков: Нехватка остатков считается накопительным итогом. Скрипт суммирует необходимое количество по каждому артикулу из всех валидных заказов и только потом сверяет с остатком в 1С.

Исправленные баги в OrderTotal.php (Задание 01)

Ошибка приведения типов: В методе subtotal цена приводилась к (int), что отбрасывало дробную часть (копейки) и приводило к занижению итоговой суммы. Исправлено на (float).

Неверная формула НДС: В методе vatIncluded налог рассчитывался по формуле начисления сверху (Сумма * 20 / 100), хотя цена уже включает НДС. Исправлено на формулу выделения НДС из суммы: Сумма * 20 / 120.

НДС без учета скидки: В методе calculate налог высчитывался из суммы до применения скидки ($subtotal). Из-за этого НДС в чеке оказывался больше положенного. Исправлено на расчет от итоговой суммы ($total).
